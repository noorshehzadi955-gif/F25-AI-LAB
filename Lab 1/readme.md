
# AI Lab 1 — Introduction to AI & Paradigms

## Objective
To compare rule-based AI with probability-based AI and understand their behavior using a scholarship-screening example.

## Project Files
- `lab1_compare.py` — Compares rule-based and probability-based decisions.
- `lab1_rules.py` — Tests a rule-based system with additional conditions.
- `Lab1_Report.docx` — Contains the report, AI timeline, test results, comparisons, and reflection.
- `outputs/` — Contains captured program outputs.

## Requirements
- Python 3

## How to Run
Open the terminal in this project folder and run:

```bash
python lab1_compare.py
python lab1_rules.py
```

## Testing
The programs are tested using scholarship-screening examples and rule-based test cases. Actual results and edge cases are discussed in the report.

## Assumptions and Limitations
The thresholds and probability values are demonstration inputs. They do not represent a trained AI model or prove prediction accuracy.
